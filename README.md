# 🚀 Personal Portfolio Website

Welcome to my personal portfolio repository! This is a modern, highly interactive, and fully responsive portfolio website built to showcase my skills, projects, and experience as a Full-Stack Web Developer.


## ✨ Features

- **Premium UI/UX:** Designed with a modern, dark-themed aesthetic featuring glassmorphism and smooth micro-interactions.
- **Dynamic Backgrounds:** Uses custom interactive "Gravity Stars" and particle animations that respond to mouse movements.
- **Fully Responsive:** Flawless layout across mobile, tablet, and desktop screens.
- **Smooth Animations:** Scroll-triggered animations for all sections to provide a cinematic feel.
- **Functional Contact Form:** Integrated with **EmailJS** to send messages directly from the website to my inbox.
- **Project Showcase:** A filtered portfolio section to display frontend and full-stack development projects.

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Styling:** Tailwind CSS &  CSS
- **Animations:** React Simple Animate, tsParticles, Animate-UI
- **Scroll Detection:** React Intersection Observer
- **Email Service:** EmailJS
- **Icons:** React Icons


## 🌍 Deployment
This website is deployed on Vercel.
*(Note: Remember to add your Environment Variables directly into the deployment platform's dashboard, as `.env` files are ignored by git).*
